# 화면 길잡이 시험 앱 (시제품 · 본 앱 아님)

> **시험용이에요.** 진짜 앱은 앱 파트(송석주) Kotlin 앱이고, 이 폴더는 11/22 ~ 27 김우석이 실제 폰으로 판단 방식을 시험할 때 쓴 자바 앱이에요. 본 앱에 그대로 넣지 말고, 아래 「본 앱으로 옮길 것」만 참고해 주세요. 지워도 되는 폴더예요.

## 무엇을 하나
- 다른 앱(코레일+ · 배민 등) 화면을 **접근성 서비스로 읽어** 폰 기록(logcat, 태그 `GUIDE`)에 남겨요.
- PC의 파이썬 판단기(`senior-guide-backend` 저장소 `prototype/guide-night-1125/`)가 무선 디버깅(adb)으로 그 기록을 읽고 판단한 뒤, 폰에 「여기를 누르세요」를 보내면 이 앱이 **동그라미 · 안내 띠**를 그려요.
- 대신 누르지 않아요(짚기만). 어르신이 누른 칸(`CLICK`) · 만짐(`TOUCH`)을 기록해 PC가 결과를 알아요.
- 「말하기」 버튼: 폰 내장 받아쓰기(구글 · 삼성)로 듣고, 쉬어도 2초 더 듣는 「이어 듣기」를 시험해요.

> 지금 구조는 **PC가 폰을 조종하는 실험 장치**예요. 실제 서비스 구조(폰 ↔ 서버 HTTP)는 백엔드 저장소 `docs/contract-v0.1.md`(파트 사이 약속 v0.2, PR #6)를 따라요.

## 파일

| `MainActivity.java` | 앱 첫 화면: 접근성 켜기 · 마이크 허용 · 시험 미션 버튼 |

## 빌드 · 설치
1. JDK 17, Android SDK 35. `local.properties`에 `sdk.dir=`(내 SDK 경로) 한 줄
2. `./gradlew assembleDebug` (Windows는 `gradlew.bat assembleDebug`)
3. 폰 개발자 옵션 › 무선 디버깅 → `adb pair` / `adb connect` → `adb install -r app/build/outputs/apk/debug/app-debug.apk`
4. 폰에서 「화면 길잡이」 앱 → 「1. 접근성에서 '화면 길잡이' 켜기」, 받아쓰기를 시험하면 「1-B. 마이크 허용」
5. PC 판단기 실행은 백엔드 저장소 `prototype/guide-night-1125/README.md`

## PC ↔ 폰 약속 (logcat 태그 `GUIDE`)
| 기록 | 형식 | 뜻 |
|---|---|---|
| `DUMP4` | `DUMP4\|패키지\|누를수있나\|입력칸인가\|왼,위,오른,아래\|resource-id\|클래스\|선택됨\|글자` | 화면의 칸 하나. `선택됨` = 지금 고른 탭 · 칩(글자 칸부터 누를 칸까지 최대 5칸 위 중 하나라도 `isSelected`) |
| `DUMP2\|end` | | 한 화면 끝 |
| `CLICK` | `CLICK\|시각\|패키지\|왼,위,오른,아래\|글자` | 어르신이 실제로 누른 칸(앱이 클릭 이벤트를 보낼 때만, 코레일+는 안 보냄) |
| `TOUCH` | `TOUCH\|시각` | 화면 어딘가를 만짐(좌표는 안드로이드가 0으로 가림) |
| `LIVE` · `CONT` · `TIMING` · `LISTEN` | | 받아쓰기 결과 · 이어 듣기 · 걸린 시간 |
| `UTT` · `STT` · `ENGINES` | | 녹음 비교 시험 · 엔진 목록 |

PC → 폰 명령(브로드캐스트, `-p com.edu.guide`): `com.edu.guide.DUMP2`(화면 읽기), `SHOW`(동그라미 · 안내: `say` · `sub` · 위치), `SET_MISSION`(`json`), `FIND`(`q`), `STOP`, `VOICE`(`mode` = listen · live · engines · set · stop)

## 실제 폰에서 찾은 것 (본 앱으로 옮길 것)
1. **화면을 읽기 전에 접근성 캐시 비우기**(안드로이드 13+ `clearCache()`). 안 하면 코레일+ 「열차 조회」 뒤 75초 동안 지난 화면 글자를 받아요.
2. **「선택됨」 읽기**: 탭 · 칩은 글자 칸이 아니라 위쪽 칸이 `isSelected`라서 최대 5칸 위까지 올라가며 봐요. 잘못 누름(배민 「돈까스 · 회」)을 알아채는 데 필요.
3. **누른 칸 · 만짐 기록**: 클릭 이벤트를 안 보내는 앱이 있어 `TOUCH`(1픽셀 창, `FLAG_WATCH_OUTSIDE_TOUCH`)도 같이 받아요.
4. **안내 띠 · 동그라미는 터치 통과**(`FLAG_NOT_TOUCHABLE`): 어르신이 안내 위를 눌러도 아래 앱 버튼이 눌림.
5. **받아쓰기**: 구글 엔진은 쉬면 바로 끊고 「최소 듣기 시간」 힌트를 무시함 → 엔진이 끊어도 2초 더 듣고 이어 붙이기(`VoiceLab.toggleListen`).
6. 비밀번호 칸 · 결제 화면 판별, 개인정보 가리기는 약속 v0.2 3-3절 · RQ-43(폰에서 먼저 거르기)을 따라 본 앱에서 새로 만들어요(이 시험 앱은 PC 쪽에서 가림).
